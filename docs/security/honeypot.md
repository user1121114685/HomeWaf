# 内置蜜罐与请求取证

在服务卡片或表格中点击“蜜罐设置”，或在“配置服务”中打开常驻的“蜜罐设置”
页签。已有服务可以随时重新进入、修改并保存，不需要重新创建或停止监听。新增的
`policy.honeypot.capture_denied` 默认为 `false`，开启后将已经被黑名单、
名单外拒绝或攻击规则拒绝的请求交给进程内仿真处理器。原命中原因、规则、
来源与处罚证据仍保留，仿真响应不连接真实业务上游。

访问总开关关闭、原有自保锁定、登录门、策略不可用、观察模式和直接断开动作
不被这个选项覆盖。关闭该选项恢复原来的拒绝响应；关闭蜜罐同样停止这个
选项的导流。原有主动选择“名单外来源导入蜜罐”的策略独立于此选项。

陷阱路径只填写确认不存在的路径。匹配使用现有规范化视图，覆盖重复编码、
点段和路径参数等变体；更换 IP 的请求仍分别经过相同检测。不要将真实的
业务登录路径或管理目录设置为陷阱。真实业务访问权限仍由原有策略决定。
URL 拒绝规则现在同时检查原始 URI 和规范化路径组成的 URI，保留原查询串；
URL 允许规则继续使用原始 URI，不因规范化扩大攻击检测豁免范围。

## 记录内容与最近 20 条

蜜罐请求的 `PipelineLog.detail_json` 增加 `honeypot` 对象，记录 HTTP 方法、
不含查询参数的路径、规范化路径、最多 256 字节的 UA，以及 TCP 对端 IP。
日志外层的 `client_ip` 是按可信代理配置解析出的来源地址，`req_id` 用于
关联同一请求的规则命中。UA 是客户端声明，不能据此确认对方使用了 AI；
同样不能仅凭相似 UA 或更换的 IP 断定多个请求属于同一人。

请求端口的来源地址取自连接，只有明确配置的可信代理才能提供转发来源。
伪造 `X-Forwarded-For` 或 `X-Real-IP` 不会自动成为真实来源。使用 CDN 或
反向代理时，只配置实际前置代理的网段。

已认证且具有安全管理员角色的管理客户端可调用：

```http
GET /api/v1/pipeline/logs?port=5000&honeypot=true
```

返回该端口最新 20 条蜜罐请求及蜜罐触发的丢弃请求，按时间倒序；过滤在数据库限量之前完成，
不混入其他端口、普通请求或处罚状态变化。省略 `honeypot` 或传 `false`
保持原有最近 100 条日志接口。管理接口沿用现有认证和传输封装。
“20 条”是查询窗口，不会删除其他日志；持久化仍经过有界日志队列，过载时
可能丢弃日志，保留期限仍由现有日志轮转和清理策略控制。

不采集来访者的桌面文件、SSH 登录记录或浏览器历史，不在响应中嵌入诱导
AI 执行本机读取或上传的指令。蜜罐交互不是终端管理通道。请求元数据不存储
Cookie、Authorization、查询值或完整正文。可选的正文归档见下文；仿真登录
尝试沿用现有账号名、口令长度及 HMAC 记录方式，不保存明文口令。

## 自定义仿真提示与权重

在“蜜罐设置”中点击“添加蜜罐提示”，直接修改页面标题、提示内容和展示权重，
也可以移除已有提示。标识自动生成，保存后保留，普通编辑无需填写 JSON。
以下是完整策略 JSON 中的等价结构：每项含唯一 `id`、页面 `title`、提示
`message`、正整数 `weight`，最多 32 项，
标题 128 字节、每条提示 4096 字节、总文案 32 KiB。权重范围 1–10000。

```json
[
  {"id":"panel","title":"管理控制台","message":"请输入管理账号。","weight":70},
  {"id":"device","title":"设备管理","message":"请登录后继续。","weight":30}
]
```

权重用于不同来源之间的展示选择。同一端口、来源和密钥下选择保持稳定，
不采信来访者的 Cookie；配置、密钥或来源改变可能改变选择。日志记录
`lure_id` 以便关联展示内容。没有自定义项时使用中性的“管理控制台”，不
复用真实登录门标题。文案通过模板按纯文本转义，不接受可执行 HTML、JS、
命令或模板；也不调用 AI 来执行其中指令。不保证仿真页面无法被识别。

## 命中阈值与丢弃响应

以下字段合并到现有 `policy.honeypot`；不要覆盖其他已有配置：

```json
{
  "enabled":true,
  "drop_after_hits":5,
  "drop_window_seconds":600,
  "drop_seconds":10800,
  "distributed_drop":{
    "enabled":true,
    "window_seconds":600,
    "distinct_ips":10,
    "seconds":10800
  }
}
```

`drop_after_hits` 默认 0，表示关闭单来源丢弃。开启后，在指定窗口内累计
实际进入蜜罐的请求，达到阈值生成本端口 `drop` 状态。多来源规则独立开关，
默认关闭；默认参数为 600 秒内 10 个不同来源触发本端口 10800 秒锁定。
重复 IP 不增加不同来源数，IPv6 按现有聚合前缀去重。普通合法流量不计入。
两个规则都要求开启自动处罚；观察事件、可信及受保护来源不自动处罚。

命中事件沿用有界异步处罚队列，后台处理事件后，后续新请求执行丢弃；不
保证在阈值那个请求返回前完成。并发请求可能已经在处理。启用任一蜜罐丢弃
规则后，蜜罐内提交或触碰陷阱不再使用旧的立即升级封禁逻辑，由新阈值处理。
原有攻击规则的其他处罚逻辑不变。队列或状态配额耗尽仍可丢弃事件，需关注
现有丢弃指标。

单来源状态与 `honeypot_lockdown` 均持久化，可在“当前处罚”中释放；有效
状态重启后恢复。多来源锁定期限固定，不因后续命中无限延长，释放后冷却
60 秒，冷却也持久化。窗口计数不持久化，重启后重新累计。已生效的处罚要
到期或手动释放，关闭开关只阻止产生新的处罚。

这里的丢弃是当前业务端口在访问与 Host 校验后的 HTTP 处理动作：HTTP/1
关闭连接，其他传输终止或复位请求，不发送蜜罐或业务正文，不连接真实上游。
它不是内核防火墙的静默丢包，不影响其他端口或管理通道，也不主动终止已经
建立的 WebSocket、下载等连接。可信及受保护来源保留现有豁免；显式黑名单
等其他访问策略仍然适用。锁定、到期及人工释放事件进入现有日志和可选通知
队列，通知发送仍取决于用户已配置的渠道。

## 仅归档，不执行提交内容

`archive_body` 默认关闭。开启后，`archive_max_bytes` 默认 16384，允许
1024–65536 字节；设为 0 使用默认值。正文最多采样上限加一个字节以识别
截断，读取截止时间为 5 秒。`detail_json.honeypot.archive` 保存采样长度、
截断标记、采样前缀 SHA256、内容类型，以及可安全分类内容的脱敏 Base64。
SHA256 是采样前缀摘要；截断时不表示完整正文摘要。

完整 JSON 和表单沿用日志统一脱敏，遮盖口令、令牌、会话与密钥字段。未知、
二进制、multipart、无效、截断或脱敏后超额内容只存摘要，不保存原始样本。
样本作为不可信数据写入有界日志队列，不作为文件路径、不解压、不启动进程、
不作为模板或 HTML 渲染、不送入 AI 执行，也不进行任何外部回连。请求中
自称的身份或指令不获得任何权限。沿用安全管理员查询权限、日志轮转与清理。

## 资源与运行平台

实现使用 Go 的 HTTP 处理器，没有依赖客户端 macOS、Windows 或 Linux 的
命令或路径。并发和随机延迟继续由现有蜜罐配额约束，过载返回 503 和
`Retry-After`，不会改为业务回源。HEAD 响应不发送页面正文。
未启用正文归档时，登录提交最多采样 16 KiB；启用时使用上述有界采样上限。
现有蜜罐状态保留 TTL 和人工释放机制；由黑名单触发的导流须解除对应黑名单或关闭导流
选项，释放自动蜜罐状态不会绕过仍然有效的黑名单。
