# HomeWaf 控制台改版

Kind: software — 面向首次使用 HomeWaf 的家庭服务、网站管理员。
Design: 延续现有蓝色盾牌品牌；中性浅底、蓝色操作色、8/12px 圆角、统一间距。skill 抽签首选 green-black-bone 与现有蓝色品牌和用户可切换的明暗主题不符，保留品牌色。字体优先中文系统字体，保证离线部署可读。

## 用户路径

工作台 → 接入服务 → 选择场景 → 填写现有服务地址 → 检查并保存 → 启用服务 → 用新入口验证访问。

新手不需要先理解流水线、上游、QPS 或 JSON。常规路径只填写现有服务地址；NAS/设备默认不强制独立访问账号，可选择额外账号、指定地区、共享 IP 组和地域/IP 组黑名单。IPv4/IPv6 地址统一在 IP 组维护，可选择已有组或直接新建。地区与组白名单为“或”关系，黑名单优先，账号与来源限制叠加。名称自动生成，推荐端口自动避开已知配置，最终由服务器预检。协议、域名限制、端口和名称放进连接选项；HTTPS 证书只在选择 HTTPS 后出现。

创建始终保留“未启用”语义。观察模式不代表拦截攻击，启用也不代表 DNS、路由器映射或公网流量已接入。界面应明确显示下一步，不能生成虚假安全状态。API 场景在创建后生成令牌，凭据不写入 localStorage。

## 功能与入口

| 用户任务                  | 常用入口           | 高级能力                           |
| ------------------------- | ------------------ | ---------------------------------- |
| 首次使用、知道下一步      | 工作台             | 原仪表盘、监控大屏                 |
| 接入 NAS、设备、网站、API | 服务接入，三步引导 | 原端口编辑器、路由、TLS、请求解释  |
| 确认是否生效              | 服务状态、启用确认 | 实时日志、trace、运行指标          |
| 调整拦截                  | 安全事件、策略模板 | IP/URL 名单、CC、OWASP、AI、插件   |
| 维护实例                  | 全部功能           | 账号、审计、通知、证书、诊断、升级 |

常用导航从权限过滤后的路由中生成。全部功能保留现有菜单并支持搜索，已有深链接保留。

## 接口编排

沿用 `/api/v1/pipeline` 下的真实接口和既有加密请求封装，不增加仅供 UI 的写接口，不绕过后端权限检查。

| 接口                         | 时机              | 交互约束                                              |
| ---------------------------- | ----------------- | ----------------------------------------------------- |
| GET overview                 | 工作台、服务列表  | 读取失败显示重试，不把失败当零服务                    |
| GET templates                | 创建引导          | 场景对应后端模板；不在前端重造规则                    |
| GET migration/legacy         | 列表              | 原有业务单独提示，迁移保留旧预览流程                  |
| POST templates/preview       | 切换场景后继续    | 将模板复制到草稿，不修改已保存服务                    |
| POST ports/check             | 连接步骤继续      | 服务器检查端口冲突；错误保留输入                      |
| POST upstream/test           | 连接步骤继续      | 仅 TCP 连通测试，不宣称 HTTP/TLS/业务验证通过         |
| POST explain                 | 保存前、启用前    | 解释当前草稿；草稿变化使旧结果失效                    |
| POST ports/save              | 明确确认保存/启用 | 新建保持 listen_enabled=false；保留 revision 并发检查 |
| `gate/*`、`state/*`、logs、stats | 高级编辑与状态    | 保留原有行为与确认流程                                |

## 视觉和文案

Voice: technical-dry，术语在首次出现时用日常语言解释，按钮写明动作，出错时给下一步。

一个页面一个主操作；相同功能使用相同名称。工作台用真实服务状态和有顺序的接入清单。服务列表默认以服务为单位，批量表格按需打开。桌面、平板、手机、深色和 reduced-motion 都应可用。

已接入服务默认打开“常用设置”：名称、现有地址、访问开关，以及账号、规则和代理的任务入口。完整规则编辑器通过“显示高级配置”展开，原高级字段保持可用。服务令牌的后续操作直接打开认证面板。启用弹窗自动预检，只要求用户选择方式并确认；完整 trace 按需展开。手机表单操作区保持可见，导航有关闭遮罩和键盘关闭方式。

这是登录后的管理应用。skill 的营销站首屏、每节一屏、照片、滚动场景、分享图及宣传式 footer 不适用于此任务；不为通过营销检查而插入装饰屏幕。应用使用实际可操作 UI，保留现有 Vue/Element Plus 控件和权限。视觉检查与行为测试分别记录结果，不将营销 gate 的失败伪装为通过。

## 验收

- 初次打开就能找到接入服务入口；常用功能与全部功能均可达。
- 地址自动补齐协议，字段错误就地显示；失败不丢输入、不重复提交。
- 选择场景不会意外关闭认证；观察启动仍保留访问限制。
- 保存后给出启用入口；API 场景提示先生成令牌。
- 手机端无页面横向溢出，关键按钮可触达，键盘焦点可见。
- typecheck、构建、现有逻辑测试、新手流程与高级功能回归、skill 检查。
