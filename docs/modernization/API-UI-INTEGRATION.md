# API 能力接入：产品流程与验收

起点：2026-11-16，`e85d03af`；依据本次 API/UI 审计。此前 AGENTS.md 引用的全控制台清单不在当前工作区，本文件只记录本次增量，不代表全控制台重构完成。

## 产品边界

- 使用现有导航、Vue/Element Plus 控件、盾牌品牌和语义 token。
- 服务防护、账号和会话以原生 pipeline 端口为唯一作用域。旧 Host API 不能直接接收新服务 ID。
- 普通操作使用明确字段和动作；保留高级配置，避免为同一能力建立第二套持久化路径。
- 读取失败不显示为正常空数据；请求失败保留草稿；保存、应用到草稿、立即撤销分别说明。
- OWASP 基线是低优先级高级设置，必须展示用户覆盖层与生效差异，不能把基线保存说成已覆盖用户调参。
- 系统配置采用受限高级维护：内置项后端保护，自定义项明确提示只有实际读取方才会使用；保留既有编辑入口。程序加载元数据时标记内置项，保护迁移不改变配置值。

### 后端定向证据

- `TestOwaspFilePreviewBoundary`：只读根目录句柄限制 `.conf`，拒绝绝对路径/目录逃逸；预览上限 2 MiB。
- `TestBaseConfigReloadPreservesUserOverrideAndPersists`：基线落盘、引擎重新发布；真实 Coraza 请求中的用户阈值继续优先。
- `TestManagedSystemConfigCannotBeDeleted`：内置项拒绝删除、扩展项可删、元数据保护迁移不改变值。
- `TestPipelineCCRecommendationUsesSelectedServiceAndRejectsSampledData` / `TestPipelineCCRecommendationPathAndStaticSemantics`：原生服务日志身份、非全量数据拒绝估算、查询错误不变成空成功、路径及静态资源口径。
- `TestPipelineCCRecentHitsPreserveCCOutcomeAndPortScope`：同一请求命中多个检测器时显示 CC 本身的观察/拒绝状态，并隔离端口。
- `TestGateBulkRevocationScopeAndTokenValidity` / `TestGateDurableRevocationAndRestart`：账号/服务范围撤销、旧令牌失效、持久化与其他端口隔离。
- `TestRuleBuilderPreviewCompilesAndMatchesNativeService`：真实旧格式生成接口输出可由原生服务编译，样例请求实际匹配；没有写入旧规则表。
- `TestAllBackendRouteAuthenticationBoundaries`：新增路由包含无令牌/失效令牌/非法角色及跨角色拒绝回归。

### 产品与验证边界

- CC 建议只用当前访问日志分区的最近 1/3/7 天，最多 50000 条；不包含归档。非 `db` 全量模式、样本不足或查询预算不足时不返回建议值。固定时间桶近似滑动窗口，包含历史攻击及部分挑战豁免流量，必须先观察。
- CC 命中看板只显示当前分区最近最多 200 条命中，不宣称累计攻击总数。各服务挑战概览展示已保存配置和监听状态。
- 原生 CC/挑战和会话管理不恢复旧 Host 写路径；旧版逐规则统计维度、验证码引擎与原生轻量挑战不作等价承诺。
- 基线保存和热重载不是事务；失败时明确提示文件可能已写入而运行实例未更新，并保留输入供修正/重试。
- 扩展配置只有被明确的程序/扩展读取才有实际效果；不把“新增记录”显示为“防护已生效”，也不提供通用密钥存储。
- 截图和运行记录在忽略目录 `artifacts/api-ui-integration/`；测试使用隔离响应与临时数据库，不接触真实服务数据。构建保留现有大 chunk 提示，未为本任务更换打包结构。

浏览器拦截响应只能证明界面流程；真实保护效果、持久化与会话失效由隔离后端测试证明。外部 AI 服务不会在测试中消耗用户配额。
