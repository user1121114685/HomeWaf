# 证书库编辑流程修正

## 任务合同（2026-11-16）

管理员从 `/waf-host/wafsslconfiglist` 的新建或行内编辑入口维护一条共享证书记录。先辨认当前证书的域名、有效期和绑定服务，再导入或粘贴 PEM 证书与私钥；自动加载和导出仍由本条记录维护，沿用 `/sslconfig/add`、`/sslconfig/edit`，不改为服务配置写入。

验收要求：

- 证书/私钥使用完整宽度的等宽多行输入，可见标签说明 PEM 起止标记；导入只是填入草稿，保存时仍由服务端验证配对。
- 编辑显示当前已保存的身份、有效期、绑定服务；更换内容后不能把旧元数据当成新证书解析结果。
- 路径自动加载、导出路径和上次导出结果完整保留；可选设置可折叠，但启用状态、导出结果和错误必须可见。路径使用单行控件，说明沿用主题 tokens。
- 底部始终可见取消/保存操作；提交中防重复和关闭，失败保留草稿并提供具体字段错误/重试；仅收到成功后退出。保存成功但导出失败需要单独说明，不能只显示绿色成功提示。
- 关闭、Esc、路由离开和刷新保护未保存修改；确认放弃后清理内存中的证书草稿，不写浏览器持久存储。
- 新建/编辑共用本任务的编辑组件，保留原列表、分页、搜索与删除入口；检查桌面/平板/手机及明暗主题、取消/保存重开/失败恢复。

## 实施与证据

已用 `CertificateEditor.vue` 统一新建和编辑，移除原两个重复弹窗及文件导入处理。PEM 输入铺满内容宽度、使用本地等宽字体；导入只填草稿并明确尚未保存，支持 PEM 证书/私钥文件。路径自动加载使用随表单保存的复选项，四个路径字段与导出结果保留。当前证书身份、有效期与绑定服务显示在顶部，修改内容后说明元数据仍属于已保存版本。

底部操作独立于内容滚动；提交中禁止重复提交和关闭。格式错误提供字段提示、错误摘要与焦点跳转；服务器解析/配对错误带 `field_errors`，在原请求客户端中按请求配置解密错误详情。网络和权限失败保留输入。`export_failed` 明确区分保存结果与导出结果，导出失败在返回列表后仍可见。列表读取失败有重试，不再显示为成功空列表。

未保存确认覆盖取消、Esc、路由变化和原生刷新提示；确认框禁用 `closeOnHashChange`，避免 hash 路由变化使离开确认自行消失。草稿只存在内存，关闭后清理；浏览器存储不写证书和私钥。
