# 管理台设计与验收

Kind: software — HomeWaf 家庭服务与网站防护管理台。
Palette: cool-grey-cobalt；冷灰底色区分数据区域，钴蓝仅用于当前操作与焦点。Type: Geist / Geist Mono，中文使用本地中文字体回退。组件半径 4 / 6 / 8px。

## 目标与范围

面向正在配置、排错和观察服务的管理员。主任务是接入服务；每个工具页保留自己的实际任务。数据来自现有 Go API，认证、权限和加密请求不改为浏览器模拟。

重构覆盖所有已注册路由以及它们使用的对话框、抽屉和配置子页：

1. 统一导航和页面骨架，直接呈现功能分组与搜索；删除顶栏/混合布局等重复路径。
2. 建立唯一的色彩、字阶、间距、表格、表单、状态与交互体系。
3. 工作台突出实际运行状态和待办；服务页突出连接、策略及监听操作。
4. 数据页使用同一指标、筛选和图表语言；设置页使用清晰分组和连续编辑。
5. 登录、帮助、个人资料、全屏与分享监控使用同一品牌体系。
6. 删除未注册、无依赖的模板示例；逐路由检查溢出、空态、操作可达性与控制台错误。

## Skill 在管理台中的适用方式

遵循 `design-taste-frontend` 的单一系统、对齐、真实内容、节制配色、易读文字、键盘访问、hover/press 与 reduced-motion 规则。主界面是实际产品，不嵌套产品样机。服务配置需要可滚动的表格、抽屉和表单，因此不强制营销 hero、满屏章节、照片、WebGL 场景或随机装饰动效。登录页可使用静态排版。字体随应用本地分发，不让内网控制台依赖外网字体请求。

Voice: technical-dry；中文操作说明短而准确，使用“服务、监听、策略、事件”等实际领域名词。失败说明原因并保留输入；仅在服务端确认后显示保存成功。

## 验收与测试

仅增加能防止严重回归的测试：权限导航、配置保存与持续编辑、登录和关键操作。构建与类型检查必须通过。使用隔离数据验收，不修改用户正在运行的 WAF。浏览器检查 1440、1024、820、768、390、320 宽度以及明暗主题；检查菜单键盘操作、长文本、错误/空状态、弹窗内滚动和危险操作确认。截图和原始报告放在忽略的 `artifacts/`；最终结果记录在本文件后续章节。

## 本次实现

- `ui/tokens.css` 定义唯一配色、字体、间距与圆角；`ui/console.css` 定义管理台、表格、表单及浮层。
- `PageHeading.vue` 和路由说明统一页面层级；`navigation.ts` 让侧栏与快捷搜索使用同一份获准路由，支持键盘操作。
- 工作台、服务接入、登录、帮助和真实个人中心采用新的页面结构。其他管理页及配置子组件统一表面、文字、字段宽度和动作控件。
- `ui/charts.ts` 为十个图表模块统一字体、坐标轴、提示框与明暗主题；切换外观保留业务数据与选择状态。
- 删除未接入的演示页面、多布局实现和任意品牌色选择。AI 助手从账户菜单或业务上下文打开。
- 修正统计页旧状态监听、运行参数页插槽和爬虫统计初始示例数字；请求失败时系统监控显示未知值。
- Geist 与 Geist Mono 本地分发；许可原文在 `LICENSES/fonts/`，来源与 SHA-256 在 `provenance.json`。

Skill 安装目录 `.agents/skills/design-taste-frontend/` 属于本机工具配置，被 Git 忽略。贡献者没有该安装时，本文件和根目录 `AGENTS.md` 提供仓库内可执行的设计约定。

## 2026-11-14 验收结果

**原始 skill 结果：`GATE: OPEN 108 (rounds used up)`，不是 PASS。** 三轮检查中的真实文字对比度和顶栏焦点问题已修复。最终工作台检查没有文字对比度、键盘焦点可见性、控件碰撞、触控尺寸或视口溢出的失败项。

| `links` | 74 | 把 Vue Router 的 `#/...` 当成 DOM 锚点；真实路由跳转由浏览器巡检验证。 |

已通过的检查：

- `node scripts/build.mjs --skip-install`：Vue/TypeScript、前端发布构建及两个 Go 可执行程序全部成功。构建器仍提示部分分包超过 500 kB。
- `npm test --prefix web`：两项导航权限/路径检查和 27 项既有应用生命周期断言。
- `node --test web/scripts/verify-field-drafts.test.mjs web/scripts/verify-onboarding.test.mjs`：11 项配置草稿与接入行为检查。
- `npm run test:screen --prefix web`：9 项监控数据检查。
- `verify-console-browser.mjs`：72 个非登录路由分别在 1440 与 390 宽度打开，共 144 次；登录另测。零运行错误、零页面横向溢出；工作台额外检查 1024、820、768、320 宽度。
- `verify-config-editing-browser.mjs`：九组重要配置操作，包括重复编辑、失败保留草稿、取消、模板保存、账号独立更新与手机编辑。
- `verify-overview-browser.mjs`：十一组检查，包括日期范围、图表渲染、日志钻取、主题持久化、空数据和失败时保留旧数据。
- `verify-update-theme.mjs`：更新源没有版本时提示信息，有新版本时打开确认对话框；测试不启动实际升级。旧版任意配色与像素位置断言已移除。

浏览器检查使用 `web/scripts/preview-console-fixture.mjs` 与隔离 API 响应；结果证明前端行为与已知接口约定，未对用户的实际防护实例执行配置操作。

### 视觉与性能复核

桌面、1024、820、768、390 宽度的实际截图覆盖工作台、服务卡片、账号表格、登录页和配置弹窗，明暗主题均已查看。平板顶栏隐藏资源快捷显示，保留导航和任务标题，避免控件遮挡；表格在手机中保留横向滚动。

本地字体压缩为 WOFF2，字形顺序与 Unicode 映射经过读回比较，总加载量从 333.4 KiB 降到 137.9 KiB。skill 性能检查的字体、请求完整性、布局偏移、首屏时间及阻塞时间检查通过。

**性能预算仍有未通过项：** 1440 和 390 两个宽度均测得约 1,887 KiB 已解析 JavaScript 和 719.7 KiB CSS，超过 skill 的 900 / 250 KiB 上限，共四个 FAIL；总传输量还有两个 WARN。完整管理台资源没有达到这套轻量页面体积预算，不宣称性能检查全通过。原始数据在 `artifacts/console-refresh/performance.json`。

单次本机 CPU 浏览器采样中，桌面 FCP / LCP 为 248 / 280 ms，手机为 244 / 244 ms；布局偏移分别为 0.056 和 0，失败请求为 0。这些是隔离预览数据，不代表用户设备或公网部署表现。
