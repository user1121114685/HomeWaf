# HomeWaf 监控大屏

入口：顶部、仪表盘菜单、页面搜索中的“监控大屏”均新开标签页，保留原管理页面。管理路由为 /#/dashboard/screen，只读分享路由为 /#/dashboard/shared?token=…（令牌位于 URL fragment 内，不进入服务端访问 URL）。

## 已完成的四项能力

1. 攻击事件飞线：每 5 秒读取真实拦截记录，按 req_uuid 去重播放，最多同时显示 16 条、每条保留 7 秒。来源采用国家／地区示意位置，不声称是精确 IP 坐标；缺少定位的来源不编造坐标。防护节点默认自动获取服务器出网公网 IP 和城市，旧逻辑节点设置也自动按此处理。优先由后端直连 IPIP 国内服务，失败后尝试 IPinfo；有经纬度时采用 IP 近似定位，否则按国家与城市在本地点位表中匹配。同名城市存在歧义或无法定位时不放置节点、不播放指向虚构位置的飞线。管理员仍可配置实际部署坐标。支持减少动态效果的系统偏好。
2. 滚动 24 小时统计：服务端决定起止时刻，按毫秒范围 (now-24h, now] 读取实时与归档访问日志。访问量、拦截数、排名、地区统计和最近 12 条事件使用相同窗口，不受浏览器日期或时区影响。
3. 全局独立访客：按来源 IP 跨站点、跨日志分区去重，IPv6 地址规范化后计数。UV 在这里指独立 IP，不是自然人数，NAT 和共享出口可能合并多个访客。
4. 只读分享：系统管理员可创建 1 至 168 小时的分享并撤销，最多 20 条同时有效。访问范围固定为全部站点的大屏汇总与脱敏事件。分享页不能调用管理写接口，不能访问完整日志；IPv4/IPv6 地址、站点名、规则详情及原始事件 ID 均脱敏。令牌只返回一次，数据库仅保存 SHA-256 摘要；过期或撤销后下一次请求被拒绝，页面清空旧数据。

分享仍受管理端安全路径、IP 白名单和域名白名单约束。127.0.0.1 / localhost 链接只适用于当前机器；需要远程分享时应先使用其他设备可访问的管理地址打开大屏。

## API

| 路径（相对 /api/v1） | 方式 | 权限 / 用途 |
| --- | --- | --- |
| dashboard/snapshot | GET | 已登录；统一大屏快照 |
| dashboard/target | POST | 系统管理员；保存自动公网 IP 定位或部署坐标 |
| dashboard/shares | GET / POST | 系统管理员；列出分享 / 创建分享 |
| dashboard/shares/revoke | POST | 系统管理员；按 ID 撤销分享 |
| public/dashboard-share | GET | 独立 X-Dashboard-Token；只返回脱敏大屏快照 |

管理端沿用原有认证与加密传输。分享 GET 使用独立请求头携带能力令牌及防重放头，响应不缓存；分享令牌不能用作 X-Token 或 X-API-Key。分享不向任何第三方服务发送数据。

节点定位服务仅接收服务端自身的出网请求，不发送日志、用户令牌或站点配置。每个服务最多等待 5 秒，后台异步探测不阻塞统计；成功缓存 30 分钟，失败 5 分钟后重试，保存自动节点设置可请求重新探测（至少间隔 1 分钟）。浏览器无需访问定位服务。只读分享中的节点公网 IP 也会脱敏。NAT/VPN/多出口环境下探测结果是出网 IP，可能不同于站点入口 IP。

## 数据与刷新语义

地图下方显示来源地区数、请求拦截占比及未拦截请求数；未拦截请求为同一窗口访问次数减去拦截次数。界面已移除“功能接入清单”和飞线状态卡，飞线仍由真实事件驱动。

所有统计基于已保留的访问日志，QPS 仍来自后端实时采样。全量模式之外的日志采样／关闭模式、分区缺失、查询超时或查询上限会显示“统计不完整”。站点配置的日志排除规则与保留策略也会影响可统计记录；不能凭现有日志还原未记录的数据。

读取使用日志生命周期读锁、租户/实例过滤、8 秒预算和短缓存；窗口最多查询 32 个分区，独立 IP 基数预算为 50 万，超出时明确标记不完整，不把失败当作真实零值。只有所有分区均不可查询时返回数据不可用。显示更新时间与服务端时区。

每 5 秒刷新；失败指数退避至最多 60 秒。隐藏页面暂停轮询，重新可见立即刷新；手动暂停、组件卸载与分享失效均停止自动请求。未知数据展示 —，已成功获取的快照在临时错误时保留并标记过期；分享失效时立即清空。

## 地图资源

底图使用 MapLibre GL JS，固定 Mercator 平面投影、朝北、零倾角。只绘制国家／地区色块、国界、真实来源点和防护节点，不显示经纬网、道路、卫星影像或三维地形。默认 100% 世界视图、以亚洲为中心，不自动放大中国。无拦截来源的国家使用蓝灰底色，有来源的国家按近 24 小时拦截次数由浅橙到红色着色，图例显示少／多；同一国家的中文名、英文名和 ISO 别名合并统计。未知来源不编造位置。防护节点公网 IP 明确位于中国时另加红色实线边界，海外或定位未知时不额外高亮。

支持 MapLibre 原生鼠标/单指平移、滚轮/双指缩放、双击缩放、放大/缩小按钮及复位（100%～600%）。地图获得焦点时，方向键平移、加减键缩放、Home/0 复位。数据刷新及主题切换不覆盖手动视角，拖拽不会误触国家选择；管理大屏与只读分享页均支持。国家色块、边界、来源点和飞线使用原生地理图层，公网 IP 节点使用同一地图的 Marker，缩放时标签和线宽保持可读。

攻击来源点（飞线起点）旁显示中文国家／地区名称，使用本地系统字体和原生符号图层自动避让，不请求外部字形服务。悬停来源点或名称显示该地区近 24 小时拦截次数及最近事件中的来源 IP、城市信息，去重后最多 8 个 IP；点击可固定弹窗，支持手机查看和复制 IP。无匹配事件时明确提示暂无 IP，不推测地址。当前来源点为国家／地区示意位置，不将事件城市名称冒充精确 IP 坐标。分享页完全沿用脱敏事件内容，弹窗不会恢复真实 IP；拖动、缩放、分享失效或来源数据清空时关闭弹窗。

左右使用 MapLibre 的世界副本连续环绕，不限制在单张地图边框内。上下沿正常平面地图平移到 Mercator 可显示的高纬区域，不再把另一半球倒置拼接，也不把平面地图伪装成三维球体。飞线在跨日期变更线时选择较短经度方向。原有 SVG 点阵、自制相机、极点镜像与副本拼接代码已移除。

world-countries.geojson 保留 Natural Earth 1:110m countries（公有领域）的国家多边形和稳定 ID，country-locations.json 保存国家名称别名及示意坐标。mapData.ts 提供颜色样式、别名合并与飞线曲线；WorldMap.vue 管理 MapLibre 生命周期、来源刷新、主题与原生交互。地图样式、GeoJSON、MapLibre 主库及 Web Worker 均本地打包，不加载远程瓦片、字形、样式或地图令牌。MapLibre 使用 BSD-3-Clause 许可证，完整许可证位于 LICENSES/MapLibre-GL-JS.txt。

地区点位为 LABEL_X/Y，不是 IP 精确位置。city-positions.json 来自 Natural Earth 1:10m populated places，保留国家、城市中文/英文别名、行政区和城市示意坐标；按国家限定查找，避免同名城市误定位。小型地区与未知名称可能无法匹配，地图明确显示未定位数量。底图运行时无需外网地图服务。
